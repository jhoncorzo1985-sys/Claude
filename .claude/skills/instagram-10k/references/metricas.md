# Métricas y revisión semanal

Registrar cada viernes (por cuenta):
| Métrica | Dónde |
|---|---|
| Seguidores (neto) | Perfil |
| Alcance / cuentas alcanzadas | Estadísticas |
| % no-seguidores en reels | Estadísticas |
| Guardados y compartidos por pieza | Estadísticas |
| Visitas al perfil → seguidores nuevos | Estadísticas |
| Retención/promedio de reproducción | Reel insights |

Reglas de decisión:
- Pieza > 2× la mediana → duplicar (nueva versión, otro ángulo, carrusel derivado).
- Pieza < 0,5× la mediana dos veces seguidas → cambiar gancho/formato.
- Ritmo: comparar seguidores reales vs. curva de metas; si va <80%, subir frecuencia de collabs y reels antes que cambiar de estrategia.

Cierre del reporte: **"Mi recomendación:"** + 3 acciones para la semana.
Guardar en `plan/metricas.csv` (fecha, cuenta, seguidores, alcance, guardados, compartidos).
