# 🗺️ Roadmap RSMV

---

## Estado Actual — MVP

```
✅ Motor de simulación (18/18 tests)
✅ Backend API (Express + Supabase)
✅ Schema de base de datos completo
✅ Frontend básico (HTML/CSS/JS)
✅ Sistema EXP + Marecoin
✅ Crowdfunding activo en Vaki
```

---

## Fase 1 — Lanzamiento Beta (Q2 2026)

**Objetivo:** Primeros 100 usuarios reales

- [ ] Deploy completo en producción (Vercel + Railway)
- [ ] Sistema de invitaciones / beta cerrada
- [ ] Primer torneo municipal de prueba (sin dinero real)
- [ ] Sistema de email automático activo (Resend)
- [ ] Landing page atractiva
- [ ] Integración de pago básica (PSE/Efecty para MC)
- [ ] App PWA (Progressive Web App) para móvil

---

## Fase 2 — Primeros Torneos Reales (Q3 2026)

**Objetivo:** 256 jugadores activos + torneos con premios

- [ ] Primer ciclo completo de torneos municipales
- [ ] Sistema de premios en COP activo
- [ ] IA-DT básica operativa
- [ ] Dashboard de estadísticas avanzado
- [ ] Notificaciones push (PWA)
- [ ] Ranking global funcional

---

## Fase 3 — Escala Nacional (Q4 2026)

**Objetivo:** 1,024 jugadores + torneo nacional inaugural

- [ ] Primer Torneo Nacional RSMV
- [ ] $4,000,000 COP en premios
- [ ] IA-DT premium con análisis profundo
- [ ] Comunidad y foros (Discord/Telegram)
- [ ] Cobertura en medios colombianos

---

## Fase 4 — Expansión (2027)

- [ ] App nativa (Android / iOS)
- [ ] Transmisión en vivo de torneos (stream)
- [ ] Marketplace de jugadores
- [ ] Torneos internacionales (Latinoamérica)
- [ ] API pública para terceros

---

## Visión a Largo Plazo

> Ser la plataforma de entretenimiento de robótica deportiva más grande de Latinoamérica.

- 10,000+ jugadores
- Torneos internacionales
- Licencias de franquicia de academias
- Transmisión de torneos en vivo
