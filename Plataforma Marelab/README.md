# 🚀 PLATAFORMA MARELAB — Laboratorio de Innovación & Creatividad (Medellín, Colombia)

> **"Contribuir para que tengamos un futuro más innovador."**
> **"Nuestro superpoder es la creatividad."**

Sitio web oficial de **Marelab**, fusionando diseño minimalista disruptivo, el modelo pedagógico de los 4 pilares **M-A-R-E**, el minijuego de predicción de 10 tiros y las 3 líneas de impacto con conexión directa a WhatsApp.

---

## 🎲 Las 6 Caras del Dado MARE & La Cultura MARE

| Cara / Dimensión | Concepto | Enfoque Pedagógico / Metodología |
| :--- | :--- | :--- |
| **M — Motívate** | **Motivación** | Activamos la motivación *intrínseca*, *extrínseca* y *trascendental*. |
| **A — Aprende** | **Competencia** | Tríada de *conocimientos, habilidades y actitud* bajo el marco STEM/STEAM. |
| **R — Recréate** | **Gamificación** | *El juego no es el premio, es el método*. Activaciones y Robot Soccer Mare. |
| **E — Emprende** | **Innovación** | Creatividad como superpoder: *fluidez, elaboración, flexibilidad y originalidad*. |
| **Divergencia (A & B)** | **Pensamiento Divergente** | Apertura de múltiples posibilidades sin sesgo de respuesta única. |
| **Semillero** | **Del Cofre al Lanzamiento** | Pipeline: *Cofre de Ideas → Modelo de Negocio → Prototipo → Lanzamiento*. |

---

## 🎯 El Reto del Dado MARE (Minijuego de 10 Tiros)
- El usuario selecciona la cara que predice.
- Tira el dado 10 veces con el motor interactivo **Three.js** en 3D o en el plano **Origami 2D**.
- El sistema calcula el porcentaje de acierto y retroalimenta con diagnósticos intuitivos e inspiracionales.
